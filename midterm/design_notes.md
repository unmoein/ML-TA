# Design Notes — Midterm Exam

**Coverage:** Naive Bayes classification by hand, neural network forward pass + MSE loss + one step of gradient descent by hand, CNN parameter/output-shape calculations, precision/recall/accuracy trade-offs in a medical diagnosis context, and manual logistic regression inference.

**Goal:** Test whether students can compute these methods by hand on small examples, not just call library functions — this catches gaps that pure coding assignments can hide.
