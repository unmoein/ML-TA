# ML-TA

Teaching assistant coursework for an **Intelligent Systems / Machine Learning** course. This repo showcases assignments, an exam, and a final project I designed and used while working as a TA — covering classical ML, computer vision fundamentals, and a modern RAG-based application.

## My Role

As TA, I:
- Designed homework assignments (concepts, structure, starter code, and analytical questions)
- Prepared datasets and supporting materials
- Wrote exam questions
- Designed and specified a capstone project (RAG + TTS pipeline)
- Graded and gave feedback to students
